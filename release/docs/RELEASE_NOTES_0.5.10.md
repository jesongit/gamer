# Gamer 0.5.10（未发布候选）

此候选因发布前安全审计发现 Wasmtime 新公告而停止，未公开发行资产。正式发行见 [0.5.11](RELEASE_NOTES_0.5.11.md)，Docker v1.0.11 对应应用 0.5.11。

- 单屏游戏画面支持 `Ctrl+C` 复制选中文字、`Ctrl+V` 粘贴电脑剪贴板文本，游戏和文本两种键盘模式均可使用；本地编辑器、设置弹窗仍使用浏览器原生复制粘贴。
- 修复局域网 HTTP 访问时「游戏操作 → 粘贴」提示无法读取系统剪贴板的问题。快捷键通过原生粘贴事件传递文本；按钮在读取接口不可用或权限被拒绝时打开文本框，粘贴后点击「发送到游戏」。复制写入权限被拒绝时也会显示可选文本。
- Android 使用设备剪贴板与粘贴指令传递中文、emoji 和换行，按 UTF-8 字节检查长度；大文本使用 HTTP 控制通道。设备回包持续读取，重复复制相同文本和取消后的迟到回包均有回归覆盖。
- 浏览器目标支持网页文本选区及普通文本输入框复制，校验当前页面身份，不读取服务器系统剪贴板或密码字段；Canvas、跨域 iframe 及游戏自定义复制机制仍需具体游戏验收。
- 保留单屏人工控制、自动化输入屏障、目标与控制代次检查；等待剪贴板期间切换目标或收回控制权时丢弃旧结果。

数据库 schema 仍为 7，官方插件固定版本不变。已有 Docker 安装沿用原 `/data` 挂载、端口与环境参数。此次发布不自动更新用户安装或操作真实账号；隔离浏览器、合成协议与自动化检查不替代实际游戏验收。
