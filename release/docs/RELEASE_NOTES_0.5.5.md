# Gamer 0.5.5

- 简化“设置 → MCP 与外部控制”：仅保留连接地址、令牌名称、有效期、查看/复制和删除，不再要求逐项配置权限、对象范围或控制会话参数。
- 令牌有效期支持 `0`（不过期）。新令牌加密保存原文，可在重启后再次查看；列表不返回原文，查看和创建响应禁止缓存。旧版只有哈希的令牌继续有效，但原文无法恢复。
- 删除令牌会先使其失效，取消直接控制和临时试跑，再移除列表记录；已受理的正式运行和持久任务保持原有冻结授权语义。
- 修复插件“卸载成功”后仍留在已安装列表的问题：原入口只删除活动版本并选中保留的旧版本；现在一次卸载该插件的全部安装版本，默认保留私密数据。依赖门禁及调用排空保持有效。
- 卸载后检查实际管理状态；市场仍有的条目显示“未安装”，已退出市场的旧插件不再残留。

简化设置创建的令牌覆盖当前开放的 MCP 功能和全部对象。操作权限在创建时固定，新插件若需要新的操作权限，可重新创建令牌。MCP 仍只接受服务本机连接，直接控制的原安全门禁保持；首版设置页不提供直接控制会话表单。

Docker `posase/gamer:v1.0.7` 使用相同应用源码；配套插件仍为 `gamer-yaml-v0.3.26`，HSR 配置包仍为 1.0.2。数据库仍为 schema 7，更新时保留原 `/data` 挂载。本次发布不自动替换现有生产容器。
