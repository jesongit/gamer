# Gamer 0.4.0

Gamer 通过统一的本机 MCP 接口连接用户选择的外部 Agent。正式脚本、素材、工作稿版本和运行证据继续保留，内置模型请求、聊天和 Agent 循环退出当前发行。

- 统一 MCP 使用独立令牌、显式权限和对象范围；外部控制继续经过设备租约、暂停屏障与帧身份校验。
- 自动化工作稿支持版本化保存、检查、私有试跑和人工发布；历史候选保持只读，旧安装内容不被重写。
- 浏览器目标完善预览节流、输入坐标、刷新与退出后的收尾，工作台改善配置包上下文、设备设置和窄屏布局。
- 定时任务历史按任务身份查询，目标或入口变化后仍可追溯旧运行；日志、Trace 与实际判断帧保持关联。
- 直播助手完善互动队列、账号确认、结果反馈与异常收尾；文字识别作为独立的可选插件能力保留。
- 配套发布七款官方插件的新目录；完整便携包携带同一份锁定插件归档，用户按需安装和更新。

## 升级

下载 Windows x64 完整包，解压后直接运行 `Gamer.exe`。使用内置更新流程可保存配置和数据快照；手动替换程序前先停止服务并备份原数据。

内置 AI 插件已经退休，新包拒绝安装或执行该能力。历史安装、私密配置和候选数据继续保留。外部 Agent 的 MCP 令牌需在管理界面单独配置，管理员登录不能替代 MCP 授权。

配置包单独发布，默认发行包不包含用户设备、账号、凭据或业务数据。本次配置目录只保留 `hsr` 的最新正式内容，云游戏日常脚本已真实复跑完成并核验 500 活跃度奖励。

## 验证范围

源码门禁、插件集成检查、发行资产哈希与便携启动由本次发布记录逐项确认。隔离测试不代表所有 Android 设备、云游戏账号、直播平台或外部 Agent 客户端已经验收。
