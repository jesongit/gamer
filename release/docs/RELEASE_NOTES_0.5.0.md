# Gamer 0.5.0

Gamer 0.5.0 将运行依赖与文字识别统一到 Core，补齐管理员账号管理，并改进浏览器首次投屏与运行排查。Windows 完整便携包解压后直接运行 `Gamer.exe`。

- **运行依赖集中管理**：在「设置 → 运行依赖」查看和配置 ADB、FFmpeg/FFprobe、浏览器、Tesseract 与语言模型。受支持的平台可按锁定来源准备缺失工具，校验大小和 SHA256，不修改系统 PATH 或覆盖用户软件。
- **OCR 内置**：无需再安装独立文字识别插件；自动化继续使用原有 OCR 函数。旧插件安装与私密配置保留，Core MCP 的识别权限需明确授权。
- **管理员账号设置**：可在管理界面修改账号和密码，变更后撤销旧管理会话，使用新凭据重新登录。
- **浏览器与运行排查**：首次导航期间有界重试投屏启动，减少首次连接失败；提供运行诊断下载，并减少生产 Trace 的额外开销。
- **文档重新整理**：主 README 展示当前界面与安装流程；插件介绍、使用示例和开发说明收口到 [gamer-plugins](https://github.com/jesongit/gamer-plugins)。

## 安装与升级

下载 `Gamer-0.5.0-windows-x64-full.zip` 并完整解压，双击 `Gamer.exe`，在本机页面完成首次密码设置。首次安装不预置游戏脚本、设备、账号或业务数据，插件在网页按需安装。

已有便携安装通过「设置 → 软件更新」升级；手动替换程序前停止服务并备份完整配置与数据，不覆盖个人 `config/`、`data/`、浏览器资料及凭据密钥。Docker 部署按部署指南替换镜像，本 GitHub 版本不自动更新任何真实安装。

配套插件目录不再分发已退休的 AI 与 OCR 插件。历史安装、工作稿版本、脚本、素材、发布事务和运行记录继续保留；模型、对话与规划由用户选择的外部 Agent 承担。

## 验证范围

发布流水线核验产品版本、源码检查、发行归档、SHA256SUMS、manifest、SBOM 和隔离便携启动。发布后的下载核验和更新/回滚结果另记入发行证据；这些检查不等同于真实 Android 设备、云游戏账号或所有外部 Agent 客户端验收。
