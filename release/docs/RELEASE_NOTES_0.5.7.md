# Gamer 0.5.7 / Docker v1.0.8

- “设置 → MCP 与外部控制”新增“允许远程 MCP 连接”，默认关闭，保存后即时生效并在重启后保留。
- 开启后可连接其他电脑或容器中的外部 Agent；复制的地址沿用当前网页协议、主机和发布端口，适配 Docker 端口映射。
- 保留独立 Bearer、令牌撤销/到期、Host/Origin、scope/对象权限和输入控制屏障；管理员 Cookie 不能代替 MCP 认证。`local_only=true` 继续限制本机。
- 关闭远程访问后拒绝新远程调用，上传过程中的请求会在派发前再次检查；本机 MCP 和已受理正式任务遵守原有生命周期。

更新服务器后，在设置页开启远程 MCP，即可通过 `http://<服务器地址>:<发布端口>/api/mcp` 接入，跨公网请使用 HTTPS。插件版本及数据库 schema 7 保持不变，已有 Docker 安装保留原 `/data` 挂载，不重新初始化。

此版本提供远程诊断入口，尚未取得用户失败任务的日志，不宣称已经修复该定时任务失败原因。
