# Gamer 0.5.8 / Docker v1.0.9

- Core MCP 补齐原媒体和录制发现：按显示名称搜索录像、读取录制详情与分页原始事件、读取真实帧索引/PTS 和 PNG；从“退出云游戏”等名称即可定位，不再要求用户手工提供内部录制 ID。
- 新增 `schedule_preview`，通过已注册调度器校验计划并预览触发时间，返回 UTC 与服务器本地时间，不创建或运行任务。
- Core OCR 支持通过 `media_frame` 识别原录像帧；准备画面与识别均纳入令牌临时工作清理，输入只接受受授权的证据 ID。
- 配套视频工作台 0.2.7 支持素材名称搜索；键盘映射 0.1.7 提供映射语法、限制和可校验示例。两者要求宿主 0.5.8，新工具仍须插件显式声明、Running 状态及实际 scope/对象授权。
- 保留默认关闭的远程 MCP 开关、独立 Bearer、Host/Origin 检查与输入屏障；按数据根隔离录制服务，只读录制发现不写回历史恢复状态。

已有 Docker 安装保留原 `/data` 挂载、端口和环境参数，更新镜像后在插件页检查并更新视频工作台和键盘映射。数据库 schema 仍为 7，不重新初始化用户数据。本次接口补齐不代表已经制作用户的退出素材或实现日常脚本超时收尾。
