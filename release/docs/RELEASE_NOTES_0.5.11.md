# Gamer 0.5.11（未发布候选）

此候选在打包时被锁文件本体版本门禁拦截，未公开发行资产。正式发行见 [0.5.12](RELEASE_NOTES_0.5.12.md)，Docker v1.0.11 对应应用 0.5.12。

- 单屏游戏画面支持 `Ctrl+C` 复制选中文字、`Ctrl+V` 粘贴电脑剪贴板文本；游戏和文本两种键盘模式均可使用，本地编辑器和弹窗保留原生快捷键。
- 修复 HTTP 访问时「游戏操作 → 粘贴」无法读取剪贴板的问题。快捷键使用原生粘贴事件；按钮在接口不可用或权限被拒绝时打开文本框，粘贴后发送到游戏。复制无法直接写入时显示可选择的文本。
- Android 改用设备剪贴板与粘贴指令，完整传递中文、emoji 和换行，并检查 UTF-8 字节长度；复制取消后的迟到回包不会被当成下一次复制结果。
- 浏览器复制校验当前页面身份，支持普通文本选区和文本输入框，不读取服务器系统剪贴板或密码字段。Canvas、跨域 iframe 和游戏自定义复制仍需具体游戏验收。
- 保留单屏人工控制、自动化输入屏障以及目标和控制代次检查，切换目标或收回控制权时丢弃旧结果。
- Wasmtime 升级至 48.0.8，修复新披露的 RUSTSEC-2026-0422、0423、0424；保持严格依赖审计，不添加豁免。0.5.10 保留为未公开的候选标签，正式发行使用本版本。

数据库 schema 仍为 7，官方插件固定版本不变。Docker 安装沿用原 `/data` 挂载、端口和环境参数。此次发行不自动更新用户安装或操作真实账号，隔离验证不替代实际游戏验收。
