# Gamer 0.5.2

- 直播助手支持 B 站付费礼物按整条消息总额折算次数、持久去重和即时余额反馈，完善免费规则、预占与结算。
- 自动化支持队列绑定的扫码登录状态，处理本人取消、重新扫码、确认与有界超时；原输入屏障和运行身份检查保留。
- Docker 可显式配置宿主本机素材与反馈地址的发布端口及精确网关来源，例外仅限只读插件素材，管理和 MCP 的真实回环认证不变。
- 通知助手明确配置保存与测试通知的反馈，附带此前 HTTP 配置包导入及 HTTPS 镜像目录修复。
- 配套官方目录：自动化 0.3.26、直播 0.2.19、通知 0.1.2，其他三款插件复用旧版本。新增原生宿主能力需要升级本体，插件单独更新不能补充旧本体实现。

Windows 完整包与 Docker `posase/gamer:v1.0.5` 使用同一 0.5.2 源码及固定插件提交。配置包 `hsr 1.0.2` 独立发布，需要在配置包页面单独更新；不预置账号或业务资源。

数据库仍为 schema 7。保留原配置和数据目录，更新前按既有流程备份；已有 Docker 安装不要再次初始化。本次发布不会自动替换任何已有安装。验证使用单元测试、保存帧及隔离合成环境，真实平台、观众互动、游戏导航与完整战斗流程仍需目标环境验收。
