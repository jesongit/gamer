# Gamer 0.5.4

- 插件和配置包页面增加来源下拉框，支持 GitHub、内网 Gitea / Forgejo，以及用户自定义 URL 预设。
- 修正多个浏览器并发新增预设时的选中项绑定，预设名称保持唯一。
- 预设保存在服务端，当前选择由各浏览器分别记住；新增、编辑、删除预设不影响已安装内容。
- 市场目录和归档通过后端同源接口读取，内网请求不依赖浏览器跨域权限；切换来源时不会混用旧目录或旧请求结果。
- 支持公开 Gitea / Forgejo Release 附件及内网私有 IP 的 HTTP 下载。保持固定大小、SHA-256、插件权限确认及配置包覆盖确认；自定义源不冒充官方来源。

内网仓库需要实际发布 `registry.json` / `packages.json` 和对应归档，单独推送 Git 源码与标签不足以提供下载。插件“URL 导入”仍用于单个 `.gplugin` 文件；仓库地址应保存为来源预设。

配套插件版本沿用已验证的官方目录 `gamer-yaml-v0.3.26`，HSR 配置包仍为 1.0.2。Docker `posase/gamer:v1.0.6` 使用相同的应用 0.5.4 源码。数据库仍为 schema 7，原 `/data` 挂载、任务、凭据和安装版本继续保留；更新前备份，已有安装不要重新初始化。

本轮验证覆盖隔离 HTTP/Gitea 目录、实际下载与哈希拒绝、认证 API、前端交互、桌面/窄屏合成预览及隔离升级回滚；不代表真实账号或设备流程验收，也不会自动更新已有生产容器。
