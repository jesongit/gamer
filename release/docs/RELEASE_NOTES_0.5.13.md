# Gamer 0.5.13 / Docker v1.0.12

- 自动化新增纯原生函数 `list_length` 与 `list_get`，脚本可按列表参数的实际长度循环；空列表和越界索引有明确语义，不增加 YAML 关键字。
- 自动化脚本库新增“多账号运行”：选择多个账号，填写一次共用参数，并行启动同一正式脚本，分别显示各账号结果；已有运行由原运行屏障拒绝，关闭弹窗后运行继续。
- 修复运行参数弹窗提交时丢失填写值的问题，完整传递字符串列表；列表摘要不再只显示前两项。
- 保存草稿后直接运行也会读取该不可变版本的参数表单，不使用正式脚本或其他版本的参数声明。

新界面需更新自动化插件至 0.3.30；列表函数和工作稿参数描述需 Gamer 0.5.13，仅更新插件不生效。数据库 schema 保持 7，保留配置、脚本、素材、任务和历史。此发行不自动更新现有安装，真实云游戏兑换将在用户更新后另行验收。
