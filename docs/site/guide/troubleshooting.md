# 常见问题

## 页面打不开

源码开发默认打开 `http://localhost:5173`，构建后的服务端界面默认打开 `http://localhost:8443`。执行 `gamer.ps1 status` 检查进程、端口和日志，避免将 HTTP 地址误写成 HTTPS。

## 首次密码无法设置

先在服务端电脑本机访问，首次设置仅接受回环来源。若提供了 `GAMER_ADMIN_PASSWORD` 或配置已有哈希，页面使用登录流程，不再进入初始化。生产模式需要预先配置密码哈希。

## 扫描不到设备

在服务端电脑运行 `adb devices -l`。确认 USB 调试授权、网络配对、完整地址和在线状态。浏览器所在电脑插入的 USB 设备，不会自动出现在另一台服务器的 ADB 中。

## 能连接但投屏黑屏

先检查 scrcpy server、FFmpeg 和 ADB 的实际路径，再查看服务端日志中的会话与帧缓存错误。跨电脑访问还需检查 WebRTC UDP 连通性；反向代理能访问 HTTP 不等于媒体链路可达。

虚拟屏创建失败时先确认 Android 与目标应用的支持情况。选择镜像模式属于显式配置变更，不会自动替你回退。

## 工作台缺少自动化或视频页签

查看插件是否已安装并成功启用、是否存在依赖或启动错误。部分插件只适用于声明的 Android 应用，选择正确应用后再检查。新安装界面后刷新页面。

## 模板一直找不到

确认模板属于当前配置，引用名称能唯一匹配；对比设备当前分辨率、游戏缩放和模板来源。使用指定帧离线测试或缩小搜索区域，检查匹配分数后再调整阈值。

## 编辑后没有生效

先查看保存状态与版本冲突。插件源代码修改需要构建新归档并更新已安装插件；仅构建开发静态 UI 不会替换已安装归档。Rust 宿主修改需要重新构建服务端。

## 视频无法导入或抽帧

检查 FFmpeg 与 ffprobe 是否可执行；视频探测与帧表生成依赖它们。使用自定义 FFmpeg 路径时，确保对应 ffprobe 可被找到。再检查文件格式、大小与剩余空间。

## 如何反馈问题

在 [GitHub Issues](https://github.com/jesongit/gamer/issues) 中提供操作步骤、期望和实际结果、系统与设备信息，以及相关错误日志。分享前移除密码、令牌及个人数据；脚本和模板只附能复现问题的最小内容。
