# 视频与录制

`gamer-video` 提供素材、项目、时间轴和操作草稿界面。媒体导入与录制由 Core 提供；提取自动化模板和生成脚本草稿还需要 `gamer-yaml` 的相关能力。

## 获取素材

- **录制设备**：选择设备后开始录制，结束时停止录制并查看素材。录制由服务端管理，关闭浏览器不会自动结束。
- **导入视频**：导入已有视频，等待 FFmpeg/ffprobe 完成探测。无需连接真实设备即可逐帧查看和离线匹配。
- **刷新列表**：用于重新获取服务端媒体与录制状态，不会自动启动录制。

设备断连、编码参数变化或存储压力可能导致录制分段。录制操作事件中的文本默认脱敏；导入普通视频通常没有 Gamer 的操作事件。

## 使用时间轴

选择素材后在舞台查看画面，拖动时间轴定位，并使用逐帧操作检查细节。帧依据实际展示顺序和时间戳定位，适用于可变帧率视频。

媒体模式下舞台操作用于查看、定位和框选，不会向当前 Android 设备注入点击。

## 项目与模板

视频项目保存素材引用、标记和校准信息。先选择配置，再创建或保存项目；项目属于该配置中的视频插件数据。

定位到目标帧后，可以进入模板提取，框选区域并保存到当前配置。离线匹配用于检查模板在指定帧上的效果。

## 生成自动化草稿

如果录制带有操作事件，可从事件生成 YAML 草稿。草稿会参考画面尺寸归一化坐标，并把间隔整理为等待建议。

生成结果需要人工检查：固定等待可替换为模板判断，坐标应确认对应应用布局。保存草稿并打开自动化编辑器后，再校验和运行；生成草稿本身不会执行设备操作。

## 媒体引用

被项目或配置引用的素材受删除保护。需要删除时先解除项目引用。导出配置默认仅登记媒体引用，需要携带视频时选择包含媒体，详情见[配置包与插件](./packages.md)。
