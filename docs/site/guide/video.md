# 视频与录制

视频工作台有三个区域，各自保存的内容不同：

| 区域 | 用途 | 保存位置 |
| --- | --- | --- |
| 素材库 | 导入、录制、预览和删除视频，查看录制历史 | 服务端媒体库，多个配置可共用 |
| 项目 | 逐帧查看、标记、校准、制作模板 | 当前配置的视频插件目录，保存视频引用而非副本 |
| 草稿 | 将录制时的操作整理成自动化脚本 | 编辑过程保留在当前视频面板内，显式保存后成为配置中的自动化脚本 |

需要启用 `gamer-video`。制作模板、离线匹配、生成及保存脚本还需要启用 `gamer-yaml`；普通预览、项目和标记不依赖自动化插件。

## 录制或导入视频

1. 连接设备并切到实时投屏，在视频的素材库选择录制设备，点击 **开始录制**。
2. 在 Gamer 投屏中点击、滑动或按键。视频和操作分别保存；仅观看画面不会产生操作记录，直接在手机上操作也不会被 Gamer 的输入观察器记录。
3. 点击 **停止并保存**，生成的视频自动选中供预览。关闭浏览器不会停止服务端录制；返回素材库后可以停止活动录制。
4. 已有视频可直接 **导入视频**，完成后自动选中。外部视频没有 Gamer 的操作事件，可制作模板，不能仅凭画面还原脚本。

“取消”会结束录制，已写入的视频片段仍保留，不等于删除视频。

## 预览、项目和模板

视频画面底部集中显示播放控制：细进度条支持直接定位，下方依次为播放/暂停、逐帧、时间、素材选择、倍速、返回实时和全屏。右侧视频工作台不再重复显示播放进度条。

点击视频画面使播放器获得焦点后，可使用 **空格** 播放/暂停，**J / 左箭头** 后退 5 秒，**K / 右箭头** 前进 5 秒。长按方向键或 J/K 连续跳转，松开停止；长按空格只切换一次。输入框、编辑器、弹窗和框选模式不触发这些快捷键，切换焦点、素材或窗口后终止长按。

点击画面可播放或暂停；按住鼠标左键左右拖动可前进或后退，慢拖用于微调、快划跨越更多时间，画面中央短暂显示跳转秒数。跳转会限制在视频首尾，单次手势最多跨越 120 秒；不会改变原来的播放/暂停状态（到达结尾时按播放器行为停止）。框选、取点和取色模式优先处理，不触发播放手势，也不向设备发送控制。

1. 在素材库点击视频，左侧舞台切换为视频预览；此时操作画面不会向 Android 设备发送点击。
2. 选择配置，再点击选中视频下的 **创建制作项目**，填写项目 ID 和名称并创建。也可到“项目”页新建。
3. 在项目时间轴定位画面，使用上一帧、下一帧或指定帧定位。帧按服务端真实时间戳解析，无固定帧率假设。
4. 点击 **精确帧**，图片加载完成后点击 **帧上做模板**，框选区域、填写名称并保存；可对该确定帧进行离线匹配测试。
5. 标记和校准修改后点击 **保存项目**。模板保存和项目保存是独立操作。

也可以暂停左侧视频后，切换工作台的 **模板** 功能，直接点击 **框选**、保存，再点模板行的 **匹配**。视频模式下框选和匹配使用当前视频的同一确定帧，不需要连接设备；播放结束后仍可对最后一帧操作。恢复播放或改变位置后，下一次匹配使用新的画面。

录制素材创建项目时关联真实录制会话，项目时间轴可载入操作事件并跳转到对应帧。一个项目可引用多个素材，但时间轴制作以主素材为准；跨片段事件需把对应片段设为主素材，或另建项目。改变主素材会重置相关校准和标记，请按界面提示确认。

## 从操作记录生成脚本

1. 在录制历史点击 **生成脚本**，或在“草稿”页从下拉框选择录制。无需手填 ID，选择后自动载入操作。
2. 勾选需要的事件；可筛选、全选当前结果、取消操作、调整顺序、写注释。
3. 选择配置后点击 **生成 YAML 草稿**，检查预览及未映射事件原因。脱敏文本和不支持的事件不会被猜测还原。
4. 填写脚本名，点击 **保存并打开编辑器**。同名脚本需要明确选择覆盖；保存失败时草稿保留，可以重试。
5. 在自动化编辑器中检查坐标与等待逻辑，再手动运行。生成和保存都不会执行设备操作或创建定时任务。

在素材库、项目、草稿页签之间切换会保留尚未保存的选择、注释、生成文本和名称。切换录制或配置时有未保存提示。刷新页面、关闭页面或卸载视频面板仍会清除未保存草稿，请先保存或复制文本。

## 录制历史中的分段和事件

- **分段**是一次录制产生的视频片段。断连、画面编码参数变化、磁盘压力可能导致分段或中断；界面显示原因，各片段可单独预览。
- 素材库只展示已收口的片段，起录时的空占位条目不会展示为第二个视频；有多个真实分段时仍分别列出。
- **事件**是通过 Gamer 注入的点击、滑动、按键等操作，包含来源与相对时间，用于定位视频帧和生成脚本。
- **已完成**只表示当时录制正常结束，不代表视频和操作文件现在还存在。历史会另外说明视频缺失、无操作记录或操作记录丢失。
- 零事件记录仍可观看视频和制作模板；没有操作记录时不能生成脚本。

## 删除和清理

被项目或配置引用的视频受删除保护。先删除对应项目，或从项目中移除素材并保存，再到素材库删除视频。

所有关联视频删除后，录制历史中的 **删除历史** 可用，第二次点击确认后清理历史和残留操作记录。进行中的录制不能删除；删除历史不会隐式删除视频。

操作事件当前位于录制首段的媒体目录，删除该素材也会删除事件文件。仍需生成脚本时，请先保存脚本；历史会明确标记事件丢失并禁用生成入口。

导出配置默认仅登记视频引用，需要携带原视频时选择包含媒体，详情见[配置包与插件](./packages.md)。
