# 任务与日志

任务将调度方式、执行入口、参数和设备组合起来。脚本描述流程，任务决定何时、在哪运行。

## 创建任务

1. 在「任务」页新建任务，选择目标设备。
2. 选择调度方式，内置方式为 `cron`。
3. 选择执行器与入口。使用 YAML 自动化时，先确保 `gamer-yaml` 已安装并启用。
4. 选择配置中的脚本，填写运行参数，保存任务。
5. 先手动运行一次，确认设备、应用和资源正确后再启用调度。

Cron 以服务端本地时区执行。浏览器关闭后任务仍由服务端调度；电脑休眠或服务停止时不会继续执行。

## 执行状态

同一设备同时只允许一个活动运行，避免不同流程争抢输入。设备忙时请求可能被拒绝，先查看当前运行。

插件缺失或停用时，依赖它的任务会保留并显示依赖缺失。恢复对应插件后，任务可重新获得执行能力。

脚本参数变化后，任务会按当前定义重新绑定：已有有效参数保留，新参数使用默认值，缺少必填值时需要补齐。不要假设历史任务保存的参数永远适用于新版脚本。

## 查看日志与报错

「日志」页用于筛选和查看服务端运行记录。工作台状态条用于当前步骤、结果和错误的轻反馈；有定位信息时可跳到对应资源或步骤。

排查时先确认：运行对应的设备和配置、脚本保存版本、首个失败步骤与详细原因。资源在运行开始后发生变化时，错误位置可能不适用于当前编辑内容，应先核对版本。
