# 认识 Gamer

Gamer 将 Android 设备的投屏、操作和自动化放进浏览器工作台。适合把重复操作编排成流程，也可以先录制一次操作，再从视频中提取模板、整理脚本。

## 先走通一条流程

1. 按[安装与首次启动](./installation.md)运行 Gamer，完成管理员密码设置。
2. 在「插件」页安装需要的官方插件，首次使用自动化时安装 `gamer-yaml`。
3. [接入设备](./devices.md)，在工作台选择 Android 应用并建立投屏连接。
4. 选择一个配置，进入「自动化」创建脚本。
5. 加入等待、点击或查找模板步骤，保存后运行，查看下方状态条。

没有预置游戏脚本时，空白工作台是正常状态。先安装插件，再创建自己的内容。

## 五个概念

| 名称 | 负责什么 | 例子 |
| --- | --- | --- |
| 设备 | 决定在哪台 Android 设备上运行 | USB serial、`emulator-5554` |
| 应用 | 决定设备上启动哪个 Android 应用 | `com.example.game` |
| 配置包 | 保存脚本、模板、映射和视频项目 | `daily-config` |
| 插件 | 提供功能界面或执行能力 | `gamer-yaml` |
| 任务 | 把执行入口、参数、设备与调度组合起来 | 每天执行签到流程 |

应用与配置分别选择。配置包的名字不需要等于 Android 应用包名；同一个应用可以使用不同配置。
