## 内容与源码范围

修复局域网 HTTP 页面缺少 WebCrypto 时本地配置包导入失败；SHA-256 回退实现随前端打包，仍向 Core 传递摘要校验。配置市场支持通用 HTTPS 前缀镜像、独立配置目录及 `packages.json` 直链，按实际目录探测，保持大小、摘要和包内元数据校验。

应用以已发布 0.5.0 为基线，仅加入本次修复、版本同步和测试；源码固定为 `dba7369e34702740388914e287bc7b1a5b4a6b49`，插件固定为 `d22287b1110a47a0bd1ec4da6a72de35f3291ce8`。Docker 标签 `docker-v1.0.4` 指向该源码。构建上下文来自两个提交的 Git 归档，未包含主仓与插件工作区其他未完成改动。

本次只发布 Docker 及部署说明，没有发布 Windows portable，也没有更新本地或远程生产安装。数据库保持 schema 7；旧版标签及其摘要逐项核对未变，没有推送 `latest`。
