# 2026-09-24：发行改为 HTTPS + SHA256

## 变更

- 启动器不再读取公钥、下载 `.sig` 或执行 Ed25519 验签；清单继续验证结构、版本、通道、路径、SHA256 与大小声明。
- 默认清单来源保持官方 GitHub HTTPS。远端 HTTP 拒绝，loopback 演练可用 HTTP；HTTPS 请求拒绝降级重定向。
- Node 校验器、打包脚本、CI 和维护文档同步移除签名前置；发布继续检查不可变资产、SHA256SUMS、SBOM、实际下载资产及包内种子。
- `signature_invalid` 更新为 `manifest_invalid`，启动器/server/Web/IPC fixtures 同步。
- `plugin-signer` 改名 `plugin-packer`，移除遗留 `sign/keygen`；插件仓 SDK 快照与独立构建同步。SDK 来源提交 `00ac834cd2fcc5181094faa47a6d0b37f79022ac`，插件提交 `0e3f105`。

SHA256 验证文件与清单一致，不能认证发布者；清单来源依赖 GitHub 账号和发布权限。未删除任何 GitHub secrets，也没有创建正式 Release。
