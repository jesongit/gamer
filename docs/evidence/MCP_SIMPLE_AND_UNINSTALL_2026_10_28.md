# MCP 简化与旧插件卸载修正（2026-10-28）

用户要求首版 MCP 设置只提供令牌、0 为永久的有效期、删除、查看和连接地址，并报告旧插件卸载成功后仍留在列表。

## 实现

- `ExternalAccessSettings` 仅请求令牌元数据与连接地址，移除权限/对象表单、控制会话表单、会话轮询和工具目录。保留名称、有效期、添加、查看/隐藏、复制、删除和读取重试。
- 管理端创建令牌时，从当时真实工具目录固定操作权限，对象范围显式写入全部对象。底层仍检查显式权限与对象范围；没有恢复内置 Agent、远程 MCP 或自动开始控制。
- `expires_in_seconds=0` / `expires_at=0` 表示不过期，认证与后台临时工作继续共用凭据有效性检查。
- 新令牌原文经现有凭据保护机制加密保存，认证继续比较摘要；重启后可查看。列表不含原文，创建与查看响应 `Cache-Control: no-store`，所有管理接口仍在原管理认证内。
- 旧存储缺少密文字段时保持摘要和权限不变，不自动重写；原文不可恢复时明确提示。删除先撤销、收尾临时工作及控制，再移除记录，正式运行和持久任务继续遵守原冻结授权。
- 原插件页“卸载”调用单版本 API，活动版本删除后会选中保留的旧版本。新增插件级 `DELETE /api/extensions/:id/installations`，在同一调用排空及操作锁下移除全部版本；停止一次，不恢复旧版本，默认保留插件私密数据。依赖检查发生在删除前。
- 前端在刷新确认仍有已安装快照时报告异常，不继续显示卸载成功；市场条目按既有统一列表规则变为“未安装”，本地独有旧插件移除。单版本 API 保留其原语义。
