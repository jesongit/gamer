# Gamer 0.2.0 正式发行记录（2026-09-25）

## 发布范围与决定

主程序版本为 `0.2.0`，三款官方插件为 `0.1.0`。以已公开 beta.7 / 自动化 beta.2 为功能基线，本次晋升只调整版本、stable 发行目录和用户文档，不增加产品功能。正式插件先发布，主仓随后锁定插件提交及资产哈希；旧 beta 标签与资产保持不变。

维护者已明确决定先发布正式版，后续问题通过新补丁版本修复。补充真机测试不作为本次公开门禁，但不能计为通过。

## 已有证据与限制

- beta.7 已完成自动化回归、实际 Windows 发行文件首装、插件安装、beta.6 → beta.7 更新及失败回滚，详见 [beta.7 记录](BETA7_RELEASE_2026_09_25.md)。这些是 beta 产物的证据，不替代正式产物核验。
- 1920×1080 真机完整匹配对象 → tap 的最终坐标验收、配套保存类型拒绝复验尚未完成；现有 WASM 自动化回归通过，不能写成肉眼观察通过。
- 未完成干净 Windows 虚拟机的人工界面验收；`0.1.1 → 0.2.0` 实际用户数据升级路径尚未复验。升级前应备份 `config/` 和 `data/`，不能用完整包默认配置覆盖已有数据。
- 本轮不重试此前被执行策略拒绝的本机服务/ADB/设备操作；CI 与发行资产校验照常执行。
