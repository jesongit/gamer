# 直播助手首版验证（2026-09-25）

实现位于独立 `codex/live-plugin` worktree；插件源码在 `gamer-plugins` 提交，宿主更新固定 gitlink，未修改运行中 Gamer 或直播姬的配置和会话。

## 交付

- `gamer-live 0.1.0` builtin 插件：设备音视频 HLS 本机素材、手动 RTMP/RTMPS 输出、B 站 OpenLive 身份码接入、开放平台已授权 OAuth Token 接入、连接状态、近期事件。
- 无共享开发者密钥、无持久化凭据、无麦克风采集、无自动正式开播、无玩法执行。
- Core 只增加平台无关媒体输出和常驻 builtin 生命周期钩子；平台请求、协议与消息语义位于插件 `host/`。
- 后台输出持有设备 activity lease；关闭页面不中断，停用/卸载/服务退出时清理。静态画面通过持续解码后的最近画面定时输出，避免重复 H.264 P 帧破坏参考链。

## 外部验证边界

本机直播姬版本 7.64.0.10819 的安装资源包含「多媒体」「可以添加拉流地址或者本地文件」，据此选择本机 HLS 素材入口。已验证 FFmpeg 可读取输出，**未在当前直播姬 GUI 实际添加素材，也未公开开播**。

B 站接口依据官方开放平台文档及 OpenLive 示例实现，使用本地模拟平台验证协议；未收到真实开发者凭据，**未验证特定应用的权限、真实主播授权和真实直播间事件**。OAuth Token 获取/刷新由使用者已有的授权流程承担。普通开发者账号不等于已获得直播接口权限。

首版 HLS 有数秒缓冲，音视频使用 CPU 解码/编码；实际设备的音频采集权限、长时间运行负载与直播姬素材兼容性须在使用环境补测。输出侧最多保留一路输出，互动侧一个平台账号；事件缓存不是可靠任务队列。
