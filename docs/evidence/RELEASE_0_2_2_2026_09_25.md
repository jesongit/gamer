## 用户升级路径与边界

- 旧 0.2.0 / 0.2.1 启动器的缺陷不能靠其自身更新流程可靠修复。先退出 Gamer（含托盘进程），备份安装目录内的 `config/` 和 `data/`，从本 Release 下载 `gamer-launcher.exe` 替换安装根目录的同名文件，再打开并更新主程序。不要用完整包内的默认配置覆盖已有配置与数据。
- 局域网访问保持；未关闭系统防火墙或自动添加放行规则。Windows 网络许可仍需用户授权，服务端路径随版本变化可能导致再次询问。
- 本机服务 / ADB / 真机操作此前被执行平台拒绝，本次不重试或更换包装绕过。完整 GUI 自更新续接主程序提交、1920×1080 真机中心点击均不能记为本次通过。
