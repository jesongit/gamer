# 视频进度条拖动后的快捷键焦点修复

当前 `ConsoleVideoStage.vue` 的点击处理跳过所有按钮和输入控件，且进度条没有拖动结束处理。原生滑块拖动后焦点会留在 input，播放器快捷键同时受焦点和输入控件过滤限制。

修复复用现有播放器键盘入口：鼠标点击播放控制按钮和进度条后恢复播放器焦点；进度条按下后跟踪 pointerId，通过 window 捕获 pointerup，覆盖控件外松手及没有 click 的情况。仅当焦点仍留在原滑块时恢复；取消、窗口失焦、切换素材及卸载清理跟踪。键盘激活控件、Tab、倍速及素材下拉保留原生焦点行为。

验证：`media-keyboard`、`console-stage-p5-regression`、`media-gestures`、`keyboard-control` 四个测试文件共 37 项通过；前端 `pnpm build` 通过，产物更新到 `server/web-dist`。本次只改前端壳，无需更换插件归档或重启 Rust 服务。

真实浏览器验收未执行：准备本地录像样例、启动独立 headless Chrome 并运行 CDP 验收的命令，在进程创建前被自动审批以 `blocked by policy` 拒绝，没有返回更具体原因。未通过换工具或拆分命令重试该验收，不将组件测试等同于浏览器实测。

手工验收：刷新页面并打开视频，拖动进度条后直接使用空格、左右箭头、J/K；也测试拖动后在进度条外松手。鼠标点击播放按钮后快捷键应可用；Tab 到进度条时方向键仍按原生滑块行为工作，下拉框保持可选。
