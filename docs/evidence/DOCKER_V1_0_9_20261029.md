## 正式镜像的隔离验收

- 检查 49 个应用文件和 390 个运行环境系统包；运行镜像无 Node/Cargo、无用户数据库或凭据文件，包含新版六款插件目录。
- Chromium 以 UID 1000 使用原 seccomp 配置和沙盒运行；系统调用、线程与子进程四项检查通过。Tesseract 英文/简体中文语言模型存在。
- 从公开 v1.0.8 创建独立合成数据卷，升级到正式 v1.0.9；配置、凭据密钥、旧 MCP 令牌、任务及启用状态保持，数据库 schema 仍为 7。
- 实际跨容器 HTTP 验证默认拒绝远程、热开启/关闭、重启持久化、旧令牌、初始化、工具枚举及撤销；非法令牌、外来 Origin、代理头、管理 Cookie 与 MCP Bearer 混用均拒绝。
- 从匿名下载的正式包安装/启用视频和映射插件，通过 MCP 按中文名称检索合成录像，读取 Alt+Q 原始事件，取得 15 帧真实索引和 PNG，实际 OCR 识别 `EXIT`，预览调度，读取映射语法，创建并按名称检索独立素材包。
- 测试只使用独立内部网络与带唯一标签的容器/数据卷，结束后全部移除；未使用生产数据、真实设备或游戏账号。
