# 直播日志与观众反馈本地验收

日期：2026-09-28。源码：官方插件仓 `gamer-live/host`、`gamer-live/ui`；宿主继续通过固定 submodule 编译 builtin。此次为本地开发更新，没有改写已发布的 0.2.4 标签/归档。

## 已验证

- 直播后端专项测试：28 项。两套官方 CMD、上舰嵌套用户、缺失字段、跨房身份隐藏、粉丝牌/礼物快照、留言撤回、稳定历史分页及超过 50 条的新增补页、已有记录跟随运行终态更新、不可用目标的公开拒绝反馈、既有 FIFO/取消/重启/冷却测试。
- 只读窗口实际 HTTP 测试：无令牌/错误令牌/其他 Origin 拒绝；只允许读取，没有运行控制路由；停止窗口后，包括已建立的长连接也无法继续读取，队列执行不受影响。
- 前端 Vitest：14 项。规则保存/开关、凭据持久化回填、运行日志翻页、固定阅读时仍刷新状态、稳定历史游标、粉丝牌缺失与未佩戴、礼物单位转换。插件 Vite 构建及 `node tools/check-plugin-sdk.mjs` 通过。
- Playwright 加载实际构建的插件 UI，使用明确的模拟数据检查 320/420/760 像素布局，无横向溢出或页面异常；检查观众卡片和横条、入队提示、重载不重播、断流变灰及恢复。截图保存在本机 `server/target/live-logs-qa.png`、`live-audience-qa.png`、`live-audience-strip-qa.png`。
- 本地 8443 服务实际加载新 `logs.read` 和插件 UI；读取保留日志，使用页面按钮打开反馈窗口，验证独立地址、未授权拒绝、刷新可继续、停止上屏后显示更新中断。浏览器登录状态探针使用模拟响应，其余 API 通过本机管理员通道授权；没有获取/修改真实用户密码。截图 `server/target/live-runtime-logs-qa.png`。
- 本地开发服务器及已安装的 0.2.4 UI 已更新到本轮第一版，8443 页面实际验收通过；正常使用需刷新页面，不代表插件市场已发布新包。最后补充的“目标不可用时先识别匹配规则、向观众反馈未受理”及无界面差异的旧变量清理仅在源码和测试中完成，未进入当前运行服务。

## 尚未验证 / 检查限制

- 未自动连接 B 站账号。本机检查时互动断开，没有本轮平台实收样本；字段契约来源为方案中链接的官方文档及合成样本。
- 未操作直播姬 GUI，没有验证真实开播采集、窗口最小化时持续采集、透明/抠色。默认使用不透明背景、保持窗口打开。
- 全仓 `cargo clippy --locked --all-targets --all-features -- -D warnings` 未通过已有告警：`server/src/browser/session.rs` 的嵌套 if、`browser/transport.rs` 的复杂类型、`recording/browser.rs` 的整除写法；`media/output_tests.rs` 的嵌套 if 与 chunks 写法；已有 `gamer-live/host/protocol_tests.rs` 的锁作用域告警。本轮未改动这些源文件，也未把这一检查记为通过。
- 最后一次部署命令（检查直播/队列空闲、复制 UI、重新构建并重启后端、启动前端）在执行前被自动批准审查以 `blocked by policy` 拒绝，没有更具体原因；整条命令均未执行。没有改换执行方式绕过拒绝。当前保留前一轮已验证的服务，最后补充改动需后续获准构建部署。
