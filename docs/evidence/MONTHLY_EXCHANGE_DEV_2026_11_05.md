# 每月兑换脚本开发与调试（2026-11-05）

## 需求
- 用线上录好的「每月兑换」视频做素材包，写每月兑换脚本（每月余烬兑换星轨专票 5 + 星轨通票 5）
- 添加每月定时任务，一个任务关联所有 4 个账号
- ESC 进入游戏前先调进入游戏函数，结束后调退出游戏函数；中间逻辑：
  1. ESC 打开菜单 → 点商店
  2. 点兑换商店 → 点余烬兑换
  3. 星轨专票 → 最大值 → 确认 → 点击空白处关闭
  4. 星轨通票 → 最大值 → 确认 → 点击空白处关闭
  5. 右上角 X → 右上角 X

## 交付物（全部部署到线上 hsr 包）
- 脚本 `automations/每月兑换.yaml`：参数 notify_success/notify_failure 透传给进入/退出云游戏函数；
  跨脚本调用 `云游戏日常_退出收尾.yaml#cloud_enter_game` 与 `#exit_cloud_session`
- 模板 14 个 `mx_*_20261105.png`：全部为文字模板（商店/兑换商店/余烬兑换/星轨专票/星轨通票/
  最大值双箭头/确认✓/点击空白处关闭/两个关闭X/退出确认框/继续游戏按钮），避开"新"角标与串流延迟数字
- 定时任务「每月兑换」：cron `17 4 6 * *`（每月 6 日 04:17，与日常 04:01 错开 16 分钟），
  4 账号并发 2，任务级通知（成功/失败都发，微信通道）

## 调试过程发现的关键缺陷（全部已修复）
1. **region 语义**：`region: [x, y, w, h]`（宽高），不是 [x0,y0,x1,y1]——ember_tab 的 region
   y 0.08+0.06=0.14 差 0.001 盖不住 tab 底部 0.141，改为 h=0.08
2. **无 region 的 wait_find 走全图 540px 缩放**，小文字模板匹配不可靠——全部模板匹配显式指定 region
3. **跨脚本函数不可用于本脚本错误路径**：`fail_with_cloud_exit` 是退出收尾脚本的函数，
   每月兑换脚本内的失败要自己调 `#exit_cloud_session` 清理后再 `fail`
4. **YAML 表达式只支持 $name 与 $name.field**：`template: $ticket.png` 的字符串拼接非法，
   参数直接传完整文件名（含 .png）
5. **ESC 在云页面层触发退出确认框**（不是游戏菜单）：增加 mx_exit_confirm/mx_exit_cancel
   模板，检测到就点「继续游戏」取消并重试
6. **点商店入口进入的是「推荐」页**：需再点左侧「兑换商店」菜单；菜单模板受当前页签底色
   影响（188 暗底/136 亮底），单模板跨账号 NCC 0.60-0.76 不稳——采用固定坐标点击
   （0.078, 0.355，两个账号菜单位置一致）兜底
7. **卡片渲染等待**：点兑换商店后卡片列表渲染需 25s+（188 账号商店数据加载慢），
   redeem_ticket 先 wait_find 票据模板 30s 再点击
