# 输入输出边界收口与本地验证

本轮在主仓开发，保留已有用户文档和数据修改。设计见 `docs/reference/IO_BOUNDARIES.md`。

## 变更

- 目标列表提供能力信息；直播互动队列复用 Core 目标上下文，浏览器不需要 Android 包名。
- Stage 提供稳定尺寸与固定画面。裁切、取点、取色、放大镜、映射叠加不再读取 video/img 原生尺寸；Android 当前帧由核心同步冻结。
- 浏览器手动键鼠经过既有映射入口；映射后的动作携带原始画面标识，核心继续检查目标、修订和运行占用。
- 命名按键在 WIT 中保留名称，Android 编码转换移回核心。未提供方案时透传；数字键码仍为 Android 专用操作。
- 录制与音视频输出按目标能力拒绝，不再把浏览器误报成设备不存在；对应 UI 操作禁用。没有新增浏览器音视频编码或多点触控实现。
- UI API 1.1、Input API 1.2，插件 SDK 快照同步。部署版本：gamer-yaml/keymap/video 0.1.1，gamer-live 0.2.4。

## 验证

- Web：85 文件、796 测试通过；包含固定帧复制与插件依赖边界守卫。
- 插件 UI：YAML 257、Video 7、Live 12 测试通过；Keymap UI 无独立测试文件，其控制器和壳接线在 Web 回归中验证。
- Rust：Keymap 18、Live 23、Browser 6（含两个 headless 本地集成测试）、架构守卫 7 项通过。
- SDK 来源/快照哈希检查、四插件归档自检、Debug/Release 宿主和壳构建通过。
- 隔离的 8444 Release 服务：真实安装的 WASM 映射执行归一化点击、Enter 按下/抬起；无方案时 W 透传，Shift+A 输出大写；导航后旧画面的映射操作被拒绝。
- 同一隔离服务：直播队列绑定浏览器，模拟本地事件入队后成功执行 YAML 点击（1280×720 中的 320,360）；录制、音视频输出返回能力不支持错误。未连接真实直播平台。
- 实际 5173→8443 页面及已安装插件：5 次框选，冻结底图不随背景变化；保存 250×149 灰度 PNG；取点归一化坐标正确；取色取得 JPEG 当前帧的 `713456`（HTML 原色 `723456`，有损预览允许通道误差）。
- Release 实际页面 1080p 本地动画：约 30.41 fps；点击显示反馈 82ms、输入显示反馈 87ms；慢客户端背压和过期输入拒绝仍通过。这是本机本地测试页结果，不代表云平台网络性能。

测试使用 loopback、`GAMER_LOCAL_ONLY=1`、`ADB_MDNS=0` 和独立 headless 浏览器资料目录；未操作云游戏账号、Android 设备、真实直播间或对外推流。临时目标和配置包均通过 API 清理。

运行版本为主仓 Release，地址仍为 `http://localhost:5173/`。刷新页面加载新插件资产，再连接目标验证。浏览器录制、音视频输出和持续触控映射仍明确不支持；已有素材导入、播放和离线编辑不受此限制。
