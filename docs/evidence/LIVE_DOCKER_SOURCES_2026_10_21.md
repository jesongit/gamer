# Docker 本机素材和反馈读取修复（2026-10-21）

## 问题及修复

现有容器将宿主 `18443` 映射到内部 `8443`，直播助手却生成 `127.0.0.1:8443` 的素材/反馈地址。宿主该端口属于另一开发实例，实际返回 404；仅改为 18443 后，Docker NAT 来源因非真实回环被拒绝，返回 403。通过保持一个宿主连接并读取容器 TCP 连接记录，确认本机实际 NAT peer 为 `172.17.0.1`。

本体新增可选 `[local_read]`：`published_port` 决定插件本机读取地址的端口；`docker_gateway` 显式固定一个私有网关 IP，仅用于 `/local/extensions/:id/*path` 的只读传输。缺省保持真实回环要求。配置拒绝零端口、网段/主机名、非私有网关以及缺少发布端口的例外。

例外仍要求回环 Host、正确发布端口、同源 Origin（如提供）、独立读取密钥与插件当前启用状态；拒绝转发头、重复 Host/Origin、其他来源和写方法。Core MCP 和管理认证未使用该配置，其真实 peer 校验未改。直播助手采用配置端口生成素材与反馈地址，保留原 `local-links.json` 的密钥。
