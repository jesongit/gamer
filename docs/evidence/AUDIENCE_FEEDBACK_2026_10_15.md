# 观众反馈网页（2026-10-15）

直播助手 0.2.10 将观众反馈设置收敛为一个开关和提示文字，开启后生成只读网页地址，供同机直播姬网页素材使用。顶部只保留一个当前任务或最近完成／失败／取消结果，其下完整 FIFO 按位置展示，底部是自定义文字；等待列表有界滚动，不截断队列。黑灰、暖白与橙黄沿用当前工作台，完成为绿色，失败为红色，文字状态同时保留。

`audience.read/save/open/close` 返回 `{enabled,url,text,version}`；地址在开启期间稳定，关闭撤销，管理面板重新挂载可读回状态。提示文字按版本保存，保留换行与空值，最多 1000 个 Unicode 字符，保存后网页实时更新。服务／插件重启关闭展示，保留文字。网页仅接受回环读取令牌，公开字段不包含入口、参数、设备或运行 ID。

## 使用与边界

在仓库根目录执行 `./gamer.ps1 rebuild` 重建本体，再在插件页导入上述 `gamer-live-0.2.10.gplugin` 并刷新页面。只重建 Web 壳不会更新已安装插件的 UI；旧的整包应用计划绑定较早脚本和哈希，不用于此次更新。

礼物链路已有 `SEND_GIFT → gift → 规则 → FIFO`：可以观察礼物 ID、名称、单条数量和观众信息；规则支持礼物 ID 与最低单条数量，一条消息最多排一次，数量不拆分运行，也不推测连送累计差。礼物价格等可观察字段不等同可用筛选条件。此次检查包含现有本地契约／队列测试，真实已授权平台推送及直播姬 GUI 展示尚未验收；审计发现的停止准入时日志展示差距和显式 null 消息 ID 边界未扩展到本次功能变更。
