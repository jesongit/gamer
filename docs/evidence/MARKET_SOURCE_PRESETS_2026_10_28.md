# 插件与配置包来源预设（2026-10-28）

用户要求插件与配置包均可从下拉框切换 GitHub、内网仓库和自己的 URL 预设，并明确选择“预设保存在服务端共享，当前来源由各浏览器分别记住”。

## 初查与原因

初查 `http://192.168.31.10:13000/posase/gamer-plugins.git` 返回 HTML 仓库页面，不是 `.gplugin` 归档；该服务未返回浏览器跨域允许头。插件页原“URL 导入”直接下载单个归档，不能将 Git 仓库地址当作市场来源。

初查时内网插件仓库的公开 Release 列表为空，源码树没有 `registry.json`。此前内网 Git 同步覆盖提交与标签，GitHub Release 附件没有自动进入内网服务；推送源码不等于发布可安装归档。

## 实现

- 两个页面复用 `MarketSourcePicker`：默认 GitHub、用户指定的内网仓库，新增/编辑/删除自定义预设，当前地址可见；内置项保持固定。
- 服务端分别保存 `plugin-sources.json` / `package-sources.json`。现有配置包来源 ID、地址和 enabled 原意保留；不会修改业务包、安装版本、凭据或任务。
- 选中 ID 仅存当前浏览器 localStorage；没有浏览器存储时仍可在当前页面使用。
- 插件来源设置和原配置包来源 API 均位于既有管理认证内；读取与下载继续使用同源接口。当前源切换清空旧候选，序号检查丢弃旧来源迟到响应。
- 公开 Gitea / Forgejo 使用 Release API，选择包含相应目录附件的最近正式发行。按 Release 的真实附件 URL 固定下载，核对来源服务器、名称、大小和 SHA-256；镜像目录中的旧 GitHub URL 不会触发公网回退。
- 配置目录继续校验包内 ID、版本、适用目标和插件依赖。插件继续经过 inspect、权限确认和宿主能力门禁；自定义来源不作为官方来源记录。
- HTTPS、GitHub 前缀镜像和静态目录能力保留。HTTP 仅允许私有/回环 IP 或 localhost；HTTP 内网直连不使用公网代理，每次重定向重新验证地址，拒绝公网 HTTP、凭据 URL 和 HTTPS 降级。
- 缓存按来源隔离。所选自建来源失败不会显示另一个来源的版本；官方源仍有既有离线附带目录回退。删除来源预设不删除已安装内容。

- 架构守卫 7 项通过；Clippy `--all-targets --all-features -- -D warnings` 通过；SDK 7 个文件与固定宿主 `ea8d105` 一致。
- Web 发行构建通过。使用独立 Vite 和合成 API 进行插件/配置包、桌面/390px 窄屏四组合验收，首次保存 8 张截图，边界修正后以 10 张确认截图复核；没有横向溢出，保存预设及刷新后选中项恢复通过。

本记录的 UI 预览和回环仓库均为隔离环境，不代表真实游戏、账号或设备验收。最终本体版本为 0.5.4，0.5.3 保留为未公开候选；Windows、Docker 与内网附件的实际公开验证另以发行回执为准，既有生产安装不会自动替换。

最终修正：服务端保证预设名称唯一，前端按本次保存名称绑定选中项，避免其他浏览器同时新增时误选；预设列表尚未读取成功时不能进入管理。新增并发及失败重试回归。内网 9 个插件附件与 3 个配置包附件已正式发布，匿名重新下载全部与 GitHub 原始发行字节一致。
