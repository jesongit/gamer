# Gamer AI 本地实施与验收记录（2026-10-01）

状态：代码、集成、mock 验证及本地插件打包完成；真实多模态模型、设备及跨游戏产品验收尚未完成。没有运行收费请求、通知实发或 ADB，没有修改用户设备。

## 实施范围

新增 gamer-ai builtin、通用多模态 Runner、可插拔任务编辑器与工作台；五种模型协议、原生/外部搜索、攻略及私有记忆、持久逻辑会话、授权预留、通知、成本预算、可选账单查询、受限 MCP。复用 YAML，同 run 执行且每次实际输入都通过模型与宿主门禁。Core 只承担运行器分发、取消生命周期、输入所有权、帧导出及 Package 实例身份。

七项审查修订均有实际实现：独立 MCP 凭据；生命周期写锁前取消；REST/DC/keymap 服务端输入仲裁；本机证据决定 verified；跨 run 预算与授权累计；NativeYamlHost 单步副作用测试及宿主释放输入；按对应终态选择通知发送方。

用户已有 `docs/PITFALLS.md` 和 `web/public/registry.json` 改动保留。产物输出到 `server/target/ai-release/`，未覆盖公开市场目录或已发行插件锁。插件工作树起始固定提交为 `837184e50331824573b58271c5b143f06ffc920b`，未跟随远端。

首版插件实现提交为 `beaa32958a1081651b4b9a6400f68ed6ffd783fc`（`codex/gamer-ai`），SDK 宿主来源固定为 `3c42176cd33eb6072a3d0ff018be58bb05b29466`。首版 `gamer-ai-0.1.0.gplugin` 为 13,053 字节，SHA256 = `8235d842d1c7f89b344b99a45b56451eb7082631e23f1c4dd9ea37e0962598aa`。后续对话与永久授权实现及最新产物见本文末尾。尚未推送，两仓提交需要一并推送后才能进行远端 CI/发布验收。

## 真实环境验收步骤

1. 准备包含本次 builtin 的宿主、插件、ffmpeg/ffprobe、Android 测试设备；按根 AGENTS.md 设置 `ADB_MDNS=0` 后连接。先用可复位的测试账号和只读/低风险目标。
2. 分别配置 API 和本地多模态模型，填写实际合同价格及有限预算，显式执行图片/工具往返测试；支持原生搜索的协议再执行组合测试。验证不支持的组合显示 unavailable，不假造来源。
3. 至少选择两种界面/玩法不同的游戏，各执行首次自然语言目标与同周期复用目标；保留 session_id、原图和事件，不编写游戏分支。逐次人工标注坐标、消耗类别、账号/周期与完成状态，统计上述指标。
4. 测试正常体力、恢复道具、货币、门票、未知数量；验证默认额外消耗受阻，免费部分继续；单次/会话/周期/长期授权准确累计、到期/撤销生效，恢复重新观察。
5. 在推理、YAML sleep/repeat、触点/按键保持期间分别停止、停用 AI、停用 YAML、接管、断开 scrcpy、重启宿主；检查 REST/DC/keymap 无混入输入、旧响应无效、触点/按键收尾、槽位释放、未知结果不重放。
6. 创建实际定时任务，关闭浏览器验证后台执行；模拟 waiting/partial/success/cancelled，核对任务终态映射、对应发送方、现有通知通道实收、未知投递不自动重发。
7. 签发短时只读及操作 MCP 凭据，验证管理员 REST/批准/裸控制/外来 run 全被拒绝；测试工具会话过期、空闲、关闭、跨凭据恢复和自主 Runner 到期取消。
8. 用专用项目/工作区/key 发少量有预算的真实请求，模拟超时，核对实际账单、缓存读写、原生工具费和待核对记录；对账凭据与推理凭据分离，供应商账号总账不能与 Gamer 账本相加。
9. 导出/复制/同字节覆盖/删除重建配置包，再启用休眠插件；攻略仍为候选，私有授权、账本、密钥、账号记录和原图不进入包。重新真实验证后才能恢复本机信任。

## 当前限制

仅 Android；未做浏览器目标、实时动作游戏时延承诺或专用游戏优化。语义门禁仍可能漏判消耗/完成/账号，需要上述真实样本验证。原生工具附加费和图像 token 的请求上界依赖供应商，严格上限还需独立供应商额度；取消不保证退款。账单查询最多七天且不自动翻完所有分页或关联请求。V1 使用统一预算模板，预算阻塞通知发送一次，没有提前阈值策略。证据保留每会话最多 200 张、账本限制大小；达到上限需管理员处理，不能静默清空。尚未公开发布插件、推送提交或改写首装发行锁。

## 用户反馈补充：0.1.1 对话、计划、超时与永久授权

已将目标页接为持续对话：简短判断、计划、实际动作/结果、截图证据、历史记录、运行中补充、选项与自由回答均有真实宿主通路。补充要求提高会话修订号，旧响应结算费用后丢弃；既有已接受操作仍使用停止/接管收尾。账号、问题、回答、deadline 与试错计数落同一持久账本，没有新 YAML 关键字或游戏分支。

输入和组合自动化之前必须提交有依据的计划，查阅本地攻略与必要搜索；网页引用只接受真实查询返回的 URL。用户教过的步骤记录真实消息序号，候选攻略长期存储，完成时由新图核验实际使用的候选，随后才有本机 verified。导入/复制/覆盖及重建的信任失效规则保留。

提问默认 120 秒，可设置 5～3600 秒；知识问题超时后默认最多自动恢复 3 次、执行 3 个经过多模态复核的可恢复动作。两项计数跨恢复/重启保存，0 可禁用，最大 10。试错不执行整段 YAML，不用额外资源，不替用户决定账号、偏好、密码/验证码或批准消费。设备忙、凭据失效或达到边界时保留进度并去重通知。取消或停用后不自动启动；外部 MCP 工具会话由原客户端继续，不提升为管理员自主运行。

授权卡片明确选择仅本次、当前目标、周期或永久，永久规则可不设到期时间，仍按游戏/账号/资源/用途匹配、累计总额度并可撤销。新的同设备同游戏目标带入私有历史账号参考值，每次额外操作仍按当前画面核对账号与消耗；不一致时不会使用旧规则。仅参考且尚无本会话规则/消费时，用户可修正账号但不清零费用；已使用授权的账号变化须新目标。不同设备不自动带入账号，新目标不带入旧周期。攻略不包含授权或私有凭据。

模型配置首屏仅 URL 与密钥，读取模型元数据选择候选；高级设置手动覆盖协议/模型，支持不提供模型列表的服务。模型列表不是图片能力验证。响应不提供费用且未配合同价格的收费测试会保留预留并停止，不能把未知费用算零；Ollama 本地费用记零。API 和本地模型真实能力仍未验收。

此次检查未修改 `server/data/`、用户的 PITFALLS 条目及公开 registry。正常服务进程保持原状；新能力须使用新编译的宿主，并在插件页导入/更新 0.1.1 归档后刷新页面。仅替换 UI 无法增加后台动作。

定时任务在账号/周期尚未确认时，也复用同设备、入口、目标及冻结配置的等待会话；新 run 不重置预算、提问及试错计数，不隐式借用其他设备会话。对应测试覆盖实际 prepare 路径与历史账号参考值的管理接口输出。

localhost:5173 的预构建插件 JS 动态加载错误已修复；5 个真实 HTTP 回归用例覆盖 import 标记、版本参数和分块。当前 `/plugin-ui/gamer-ai/plugin.js?import` 返回 200，并已同步最新开发 UI；登录后的完整真实操作仍需新版宿主验收。
