# 暂停视频当前画面匹配优化

2026-09-22：模板列表和步骤匹配直接复制播放器已解码的原分辨率帧，以 PNG 上传给
`POST /api/capabilities/vision/test` 的 `image_png` 参数。此路径不请求帧表、不调用
FFmpeg、不访问设备；后端 PNG 只解码一次，复用原有 NCC。服务端确定帧裁切仍保留。

本机 debug 服务、1920×1080 素材约 240 秒处，同一 PNG 和模板的 HTTP 接口对比：

| 输入方式 | 接口耗时 |
| --- | ---: |
| 媒体帧索引，服务端抽帧后匹配 | 8791 ms |
| 直接上传当前帧 PNG，首次 | 582 ms |
| 直接上传当前帧 PNG，再次 | 571 ms |

两种输入均返回未命中，结果一致；测试图片为 788267 字节。上述计时包含本机 HTTP
请求及匹配，不包含浏览器复制/PNG 编码时间，也未计算旧前端提前取帧的额外开销。
该对比约快 15 倍，不代表所有素材和模板的固定耗时。

验证：51 项前端测试通过，覆盖原始尺寸读取、禁止重复取帧、播放/跳转/换来源的
过期结果丢弃；后端覆盖图片来源互斥、非法/过大输入、上传图像实际命中坐标、
原有媒体确定帧与模板 plugin 显式寻址。前端生产构建和插件归档自检通过。
本机服务已重新构建启动，gamer-yaml 3.1.9 已通过更新接口安装且处于 running。
