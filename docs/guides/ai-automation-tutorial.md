# 工作稿与外部 Agent 使用流程

原内置 AI 自动化已退休。Gamer 保留编辑、素材检查、私有试跑、全部版本和人工发布；模型、对话与决策由你选择的外部 Agent 承担。此文保留原链接，新的连接和权限说明见 [统一 MCP 接入指南](external-agent-mcp.md)。

1. 选择配置包，在自动化的“工作稿与版本”中创建或导入脚本。
2. 手动编辑完整 YAML，或让外部 Agent 经 MCP 读取语法、函数、素材后保存新版本。
3. 省略素材关联时保留原关联；纯等待、输入和逻辑修改无需重新选择图片。新模板从明确来源的原始 PNG 裁切。
4. 检查语法与素材匹配。它们不执行设备输入，也不证明实际流程成功。
5. 连接目标后明确测试所选版本，按返回的 run_id 查看实际步骤、错误及判断截图。私有试跑的令牌失效会取消并收尾。
6. 修改后保存下一小版本，再次检查/测试。用户满意后在 Gamer 发布大版本，正式脚本及定时任务使用发布资源。

新源码、函数、截图素材和全部旧版本保留原存储路径。旧候选可以查看并精确导出，显式导入为新工作稿；同名冲突拒绝，不覆盖旧记录。旧 job/usage 仅作历史展示，不恢复模型请求。

真实游戏、外部 Agent 长时执行和 Android/浏览器输入效果需要单独验收。本轮源码改造未部署到现有安装。
