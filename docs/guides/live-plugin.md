# 直播助手接入

`gamer-live` 提供设备画面/游戏音频输出、B 站直播互动连接与消息查看。直播姬负责素材合成、麦克风与开播，插件不包含具体互动玩法。

「直播设置」还提供自动直播模式：空闲时循环播放服务端本机文件夹的视频，匹配弹幕后切到执行设备画面，沿用现有 FIFO 执行函数或自动化；队列清空后恢复视频断点。该流程由插件后台管理，不需要常驻脚本，不占设备运行槽。停止流程会封住新触发、清理等待项、取消本流程当前互动并等待收尾，再关闭输出；互动账号连接保留。

完整操作、权限要求、动作参数和平台扩展边界见 [插件说明](../../plugins/gamer-live/README.md)。本插件需要配套的 Gamer 原生实现，旧本体安装会拒绝未知 builtin 或权限；不能仅靠安装 UI 包增加原生能力。

推荐同机使用：插件开始本机素材输出 → 复制地址 → 直播姬添加「多媒体」素材 → 粘贴地址。该地址是拉流素材地址，不是 B 站推流服务器地址。另提供手动 RTMP / RTMPS 输出。

需要上屏排队进度时，在「直播设置」打开「观众反馈」开关，将网页地址交给同机直播姬的网页素材。网页显示空闲／任务状态、一个当前或最近完成的任务、完整等待队列，以及在直播助手编辑保存的提示文字；关闭开关停止读取，互动任务继续执行。视频素材和反馈网页都复用本体端口（默认 8443），地址固定，关闭时也可复制；停止再开或重启服务后无需重新填写。

凭据由每位用户自己填写，保存到服务端本机私有配置，Windows 使用当前系统账号的 DPAPI 保护，页面不回显秘密，不进入 Package、不预置共享开发者密钥。OAuth 模式接收用户已经取得的 Token，不提供授权回调和自动续期。

「用户管理」可查用户名或完整 open_id，修改余额或设为无限次；新人默认 1 次，互动规则可配置每次消耗。入队先预占，日常只在最后领奖实际核验后扣除；失败、取消和确认超时退回。次数不足不会排队或切换到设备。身份绑定平台、应用、直播间和 open_id，重连及改昵称不重置次数。

配套云游戏脚本在扫码后检测到进入游戏按钮时等待本人弹幕「确认」，确认前不点进入。本人「取消」或 5 分钟超时则直接执行更多、退出登录、确认，之后继续后续观众。控制消息不收费，其他观众或非等待阶段的确认取消均无效。正常日常结束仍重置输入并退出登录。

「直播设置 → 主动弹幕」配置独立发言账号的 SESSDATA、bili_jct 和房间 ID，可编辑自动提醒并手动提交弹幕。设置已保存不等于实际账号已经验收；刷新发言状态查看结果。发送在独立后台限速、去重，失败不会阻塞日常任务，模拟任务不会触发真实发言。

本轮本地证据与待实连项见 [验收记录](../evidence/LIVE_USERS_CONFIRMATION_2026_10_16.md)。源码变更需要重建本体并配套 gamer-live 0.2.14、gamer-yaml 0.3.19。候选资源准备后，`node tools/live-workflow/apply-users-confirmation.mjs apply` 会检查新宿主能力、脚本哈希、现有版本和直播空闲状态，按收尾、主脚本、规则的次序发布；它不会启停服务、开始任务或发送设备输入。

Core 新增 `media.stream`（media 域）与 `live.connect`（runtime 域）的显式权限门禁；后者只允许插件内受控的平台连接，不开放任意网络或 shell WIT。常驻 builtin 服务经 ExtensionService 的生命周期钩子接入，停用和服务退出均关闭后台任务。
