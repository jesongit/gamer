# 直播助手接入

`gamer-live` 提供设备画面/游戏音频输出、B 站直播互动连接与消息查看。直播姬负责素材合成、麦克风与开播，插件不包含具体互动玩法。

完整操作、权限要求、动作参数和平台扩展边界见 [插件说明](../../plugins/gamer-live/README.md)。本插件需要配套的 Gamer 原生实现，旧本体安装会拒绝未知 builtin 或权限；不能仅靠安装 UI 包增加原生能力。

推荐同机使用：插件开始本机素材输出 → 复制地址 → 直播姬添加「多媒体」素材 → 粘贴地址。该地址是拉流素材地址，不是 B 站推流服务器地址。另提供手动 RTMP / RTMPS 输出。

凭据由每位用户自己填写，仅在当前服务进程内持有，不进入 Package、不预置共享开发者密钥。OAuth 模式接收用户已经取得的 Token，不提供授权回调和自动续期。

Core 新增 `media.stream`（media 域）与 `live.connect`（runtime 域）的显式权限门禁；后者只允许插件内受控的平台连接，不开放任意网络或 shell WIT。常驻 builtin 服务经 ExtensionService 的生命周期钩子接入，停用和服务退出均关闭后台任务。
