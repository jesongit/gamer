# Gamer 前端界面重写实施记录

## 范围与约束

- 重写真实 Vue 前端，不把交互原型作为产品页面，不引入模拟业务数据。
- 保留当前工作区已有的 API、YAML V1、中文函数名、模板加载、设备强制重连等未提交修正。
- 保留 Core / Plugin / Package / Android App 边界；业务功能继续由实际安装且 Running 的插件贡献。
- 设计未覆盖的情况依据真实能力补齐，并在最终报告记录选择及限制。
- 设计规范：`docs/design/gamer-ui-spec.md`；最终报告：`docs/reports/gamer-ui-rewrite-report.md`。

## 实施顺序

1. 建立基线、功能清单与设计规范。
2. 重写设计令牌和公共控件；应用外壳、导航、投屏双行工具条、配置上下文、居中分屏。
3. 实现轻操作反馈条及插件反馈契约；连接真实坐标、编辑与运行错误定位。
4. 重写脚本/函数统一编辑交互、紧凑必填参数、更多菜单与重命名。
5. 统一模板、按键映射、视频、任务、日志、市场、插件管理、设置、登录及弹窗。
6. 执行回归测试、构建、浏览器验收，修正问题并完成报告。
