# ADB 统一与插件独立交付实施计划

2026-09-20，用户已确认：删除 Docker 支持；设备统一通过 ADB 接入，屏幕模式独立；官方插件目录、ID、发行包名统一 gamer- 前缀；插件可独立构建安装更新；保留旧数据并允许一次性转换，不保留旧 ID 运行兼容分支。

## 实施合同

- 不删除 docker-data 或用户设备、任务、配置、媒体数据。数据转换前备份，冲突拒绝覆盖；旧 ID 转换只作用于结构化身份和引用，不能替换用户脚本文本。
- 设备不再区分真机、模拟器、容器；扫描 ADB serial 与添加网络 endpoint 为同一设备管理入口。网络重连根据 endpoint 而不是设备类别决定，多个同型号设备不能按名称合并。
- 虚拟屏使用独立屏幕参数；不支持时明确报错，不能静默改变运行目标或坐标系。
- plugins/gamer-yaml、plugins/gamer-keymap、plugins/gamer-video 分别拥有 manifest、业务源、UI、测试、构建入口、README。共享 SDK 留 sdk；主程序保留稳定设备、媒体、录制、任务、资源、插件运行机制。
- 独立交付必须验证插件构建、安装更新及界面加载；仅移动源码或通过 path 引入重新编译主程序，不算独立交付完成。
- 保留现有 UI 布局、编辑器、控制行为与权限边界。iframe 沙盒、CSP 和插件权限检查不能因拆分被关闭。
- 清理 Docker 构建、发布、升级、专属模式与测试；通用 NAT/远程网络能力不因删除 Docker 而删去。
- 完成后同步 README、插件开发指南、AGENTS 与工作报告；明确列出未能实测的环境项。
