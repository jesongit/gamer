# 统一运行依赖与 Core OCR

用户已于 2026-10-19 授权实施，先 Debug、本地隔离测试，通过后才更新 Docker release。

- OCR 识别队列、输入大小、进程超时/取消及坐标转换移入 Core，YAML `ocr`/`find_text` 保持原语义；不再要求安装或启用 gamer-ocr。
- 管理接口集中在设置的“运行依赖”。指定路径优先；自动模式检测兼容的系统/已有依赖，再取受管理版本；失效的显式配置报错，不静默改用其它工具。

- Windows x64 复用既有 adb/FFmpeg 发行锁与 OCR 安装提取逻辑；Docker 依赖在构建时安装、运行时检测。其它平台缺少受验证安装源时明确显示原因，不执行 sudo、不更改系统包。
