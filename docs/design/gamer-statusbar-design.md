# Gamer 状态条：功能归属与交互设计

2026-09-19，按当前实现逐项检查。延续黑灰主题、29px 单行、12px 文字、无徽章边框的轻状态条；不增加通知中心或展开式运行控制台。

## 布局与显示顺序

左侧左对齐，优先显示最近操作结果及便捷动作，随后用较弱文字显示键盘/取点模式、当前画面信息。右侧右对齐，显示当前插件正在处理的内容。标签“内核/插件”只用于可访问名称，不占可见宽度。

示例：

```text
点击了 (300, 500) (0.1563, 0.4630) · 键盘控制已启用 · 1920x1080 · 60 fps · 20 ms · 4.2 Mbps | 未保存
已取色 ffcc00 (300, 500) · 1920x1080 · 60 fps · 20 ms · 4.2 Mbps                           | 运行报错 · 未保存  跳转 详情 复制
视频 · 1920×1080 · 已暂停 · 00:02 / 00:03                                                 | 草稿未保存
```

示例的像素、帧率、延迟、码率均由实际来源更新，不使用占位示例值冒充测量。像素坐标和相对坐标分别可复制；相对值为 0–1，不含 `%`。取色复制采样函数返回的六位 hex；区域复制 `[x,y,w,h]` 像素范围。

默认左右均分，分界在 20%–80% 之间拖动；比例仅保存在当前浏览器，键盘左右微调、Home/End 到边界，双击恢复均分。分界独立于投屏/编辑区分隔条。实际网格先扣除 6px 分界再分配剩余宽度，避免总宽度多出 6px。

## 所有相关功能的处理表

| 功能/状态 | 位置与表现 | 更新、清除与便捷操作 |
| --- | --- | --- |
| 实时分辨率、FPS、ms、Mbps | 左侧，低强调文字 | 仅已连接的实时来源显示；断开隐藏，媒体模式切换为媒体信息；不占用投屏工具条或画面浮层 |
| 键盘控制已启用 | 左侧 | 必须有连接、可控制实时来源、键盘焦点，且不在取点/取色/框选操作中；去掉舞台高亮边框 |
| 取点、取色、框选进行中 | 左侧，`点击取点/点击取色/框选中 · Esc 取消` | 模式结束自动消失；不再重复弹常规操作提示 |
| 点击/滑动 | 左侧最新结果 | 分别复制像素和 0–1 相对坐标，不追加历史；未消费的普通设备触控保留原控制语义 |
| 编辑器取点/取色 | 左侧最新结果 | 取点提供两种坐标；取色提供 hex 和像素位置，仍写回原编辑字段 |
| 框选范围 | 左侧最新结果 | 提供像素 `[x,y,w,h]` 复制；框选/命中框是空间标记，仍留在画面上 |
| 媒体来源 | 左侧 | 显示当前素材尺寸、播放/暂停和当前/总时间；不拿 WebRTC 的 FPS/码率冒充文件播放指标 |
| 连接、断开、静音、截图、粘贴 | 左侧简短操作结果 | 成功不重复 toast；失败可保留原有必要提示或状态详情，粘贴不输出用户文本正文 |
| 设备刷新、强制重连、应用读取/切换、APK 安装 | 左侧操作结果或受理进度 | 异步操作采用序号，旧结果不能覆盖新操作；后台静默读取不刷状态；应用启动/停止仅提示正在处理，不声称设备已经完成 |
| 设备设置保存 | 左侧保存成功 | 表单缺项/保存失败仍留原有可见错误处理；不会把弹窗中的必需错误藏到底栏 |
| 自动化/函数编辑保存 | 右侧 | 保存中、未保存、已保存；主保存按钮仍在编辑器，不在状态条复制一份 |
| 自动化/函数运行 | 右侧 | 当前步骤/运行中，提供详情；运行报错可与未保存共存，跳转、详情、复制不覆盖草稿 |
| 模板上传、替换、匹配、保存 | 右侧自动化插件反馈 | 保留已有接入；错误可复制/看详情，画面空间结果保留命中框；模板编辑弹窗内校验继续原处处理 |
| 按键映射 | 右侧 | 错误优先于“正在编辑”；取点/录键操作说明优先于普通编辑状态；当前映射名和文本模式未生效提示进入右侧，移除投屏里的名称状态徽标；空间键位标记保留 |
| 视频素材导入/删除 | 右侧视频插件反馈 | 导入中显示文件名，成功显示结果；媒体引用保护错误仍在列表可见，并提供详情/复制 |
| 录制开始/处理/活动会话 | 右侧视频插件反馈 | 从真实会话显示状态、事件数、详情；停止/取消显示结果。属于视频面板发起的操作，不因为底层 API 是 Core 就放到左侧 |
| 视频项目 | 右侧，仅项目子页面 | 未保存/保存中/已保存；媒体引用同步中和同步失败单独表达，不能显示保存成功掩盖后续失败 |
| 视频草稿 | 右侧，仅草稿子页面 | 读事件、生成中、保存中、未保存、已保存及错误；切页不残留项目保存状态 |
| 任务创建/保存、启停/挂起/恢复/取消/删除、手动触发 | 左侧 | 常规结果接入；手动触发只说明已触发，不声称任务执行完成；必填/参数校验与设备占用冲突仍由表单或确认框承载 |
| 日志 | 左侧显示主动清空结果 | 不把日志条目持续滚入状态条；自动刷新、筛选和日志正文保留列表 |
| 配置包管理 | 左侧 | 导入、覆盖、导出、新建、复制、删除及元数据保存结果；字段和版本冲突继续留详情表单 |
| 配置市场安装 | 左侧 | 成功/失败接入，覆盖确认保留 |
| 插件安装、权限、依赖、更新/卸载 | 保留市场/插件管理页的就地回执与错误 | 管理现在直接嵌入页面；权限、执行类型变化、依赖拒绝和恢复措施仍在操作旁展示，不藏到底部；必须决策的确认继续保留 |
| 系统更新 | 左侧主动检查/下载受理、安装/回滚完成、策略保存 | 等待断连恢复、安装失败、超时及人工恢复仍留升级确认流程；后台轮询不循环覆盖用户结果 |
| 第三方 declarative/iframe 状态 | 右侧当前插件 | 使用原有 `status.set/clear`，只接受宿主确定的当前面板身份；复制/详情/已注册面板跳转，禁止传入可执行函数或 HTML |

## 内容溢出时怎样操作

正常仍然一行，超出各自分界就裁切。只有发生溢出时，鼠标悬停或键盘聚焦才在对应一侧上方展示同一条内容；展开区没有标题、卡片字段列表和历史记录。

展开区允许换行，最大宽 640px 且不超视口，最高 35vh；其中复制、详情、跳转都是真按钮。这样不仅能“看全”，也能操作原来被裁掉的按钮。移出且焦点不在该区域时收起，Esc 可收起，左右区域各自对齐自己的边缘。空区域不增加键盘 Tab 停靠点。

复制成功只短暂提示“已复制”；权限受限或复制失败明确提示。详情使用已有紧凑弹窗。便捷跳转异常被捕获并显示详情，不留下未处理 Promise。主按钮、重试执行、保存、运行、停止不放在补全区里。

## 更新与归属规则

1. 实时画面数据与操作结果分开存储。FPS 更新不能覆盖坐标、截图或任务结果；结果优先排列，避免指标把主要操作挤出视线。
2. 当前插件/视频子页面负责自己的状态。卸载旧子页面时，只清除它自己发布的消息；不能误清同插件新子页面刚发布的状态。
3. 状态错误先于普通编辑说明。运行报错不因草稿变脏而消失；无法精确定位时退到只读来源预览/详情。
4. 切设备或画面来源清理旧坐标结果；在任务、日志、设置等全局页面间切换清理过期宿主结果。普通插件页签之间切换保留仍有效的左侧坐标，右侧跟随新面板。
5. 异步动作使用操作序号；新操作、上下文失效后旧请求不能回填。每侧保留最新操作，不额外增加定时消失的通知队列或消息数据库。
6. 颜色只表达必要语义：普通/次要文字、错误红、成功绿、提醒黄。实时指标不逐秒播报给屏幕阅读器，也不把成功包装成大绿框。

## 本轮验证与边界

- 全量前端测试 888 项通过；新增覆盖：溢出内容可展开并复制、Esc 收起、分界持久化、便捷动作失败、同插件旧子面板卸载不抹掉新状态。最后的详情焦点/Esc 调整后，相关 18 项再次通过，生产构建通过（保留既有大块体积警告）。
- 当前 Chromium 真实加载组件，在 800px 窗口验证：底栏 29px，页面 scrollWidth=800；均分左侧约 397px（正确扣除分界）；80% 分界时右侧约 159px，补全区仍完整落在视口内。实际点击复制成功，模拟数据明确标注，不连接设备。
- API、设备控制和脚本执行流程未重写。本轮没有把真机、断网、浏览器权限变化、所有第三方插件适配或屏幕阅读器全量测试算作已验证。
- 个别已有表单/插件中心/权限或连接冲突提示继续采用就地信息或 toast，属于有意保留。状态条不承担必须先作决定的交互，也不承诺每个后台动作都有常驻状态。

实现入口：`OperationStatusBar.vue`（分界/动作）、`OperationStatusZone.vue`（裁切与补全）、`OperationMessage.vue`（统一消息按钮）、`operation-feedback.js`（操作序号）、`useOperationStatus.js`（面板生命周期）、`Console.vue`（来源/输入指标）。
