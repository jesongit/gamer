配置包与插件 ​

配置包保存业务数据，插件提供能力。安装插件不会自动安装某个游戏的脚本，导入配置包也不会自动下载其依赖的插件。

管理配置包 ​

在「配置包」页管理本地配置，同时浏览配置市场。可新建、复制、编辑信息、导入和导出配置。

在工作台切换当前配置后，自动化、函数、模板、映射和视频项目使用该配置的数据。一个包可以声明多个 Android 目标应用；该声明用于兼容性提示，不会替代工作台的应用选择。

配置包 ID 使用小写字母、数字及允许的分隔符，不直接套用含大写的 Android 包名。

导入与导出 ​

.gamerpkg 是配置包传输格式。导入同 ID 配置时先确认冲突与覆盖范围；覆盖会替换目标配置内容。

导出默认包含配置资源和媒体引用登记。勾选包含媒体时才附带视频字节，体积和配额限制可能影响导出。仅导出引用的包，在另一台电脑上需要有匹配的媒体才能恢复素材。

配置包导出不包含全局设备、任务、账号和插件安装状态。备份整个部署时，应停机后保存数据目录与配置文件。

管理插件 ​

「插件」页将本地与市场条目合并展示，支持安装、启用、禁用、更新和卸载，也支持导入本地或 URL 归档。

.gplugin 包含插件清单、可选 WASM 和界面资产。安装前检查权限与来源。必需依赖缺失、未启用或版本不兼容时，插件不能启动；可选依赖缺失可能只影响部分功能。

如果插件被其他运行中的插件必需依赖，需要先停用依赖方。插件数据与安装状态分别管理：未安装插件对应的配置资源仍保留，以便恢复能力后继续使用。

更新界面 ​

插件 UI 在一次页面生命周期内保持固定。更新成功后先保存编辑内容，再刷新页面加载新版。宿主模块的 ui.host 权限允许其在主页面中执行；只为可信来源授予该权限。
